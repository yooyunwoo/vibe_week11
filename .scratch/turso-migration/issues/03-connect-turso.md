# 03: Turso 연결하기

**What to build:** 로컬 파일 데이터베이스 대신 Turso 원격 데이터베이스에 연결한다. 접속 주소와 비밀 키는 환경 변수로만 받고, 코드와 GitHub에는 올라가지 않는다. 접속 정보가 없으면 무엇이 빠졌는지 알려 준다. 표를 만드는 명령으로 Turso에도 같은 표를 만든다. 사용자가 Turso에 가입하고 데이터베이스를 만들어야 하는 단계라서, 필요한 준비 순서를 안내 문서로 남긴다.

**Blocked by:** 02 (화면이 서버 함수로 저장소 호출하기)

**Status:** ready-for-agent

- [ ] 접속 주소와 비밀 키는 환경 변수에서만 읽고 소스와 저장소에 들어가지 않는다(.env 계열은 이미 무시됨)
- [ ] 접속 정보가 없거나 잘못되면 빠진 항목을 알려 주는 오류가 나온다
- [ ] 표를 만드는 명령으로 Turso 데이터베이스에 같은 표가 만들어진다
- [ ] 앱이 Turso에 연결된 상태로 모든 기능이 이전처럼 동작하고, 다른 기기나 브라우저에서 열어도 같은 목록이 보인다
- [ ] 필요한 환경 변수와 Turso 준비 순서가 문서로 남는다(비밀 값은 적지 않는다)
- [ ] 자동 테스트는 여전히 로컬 데이터베이스로만 돌고 인터넷이 필요 없다
