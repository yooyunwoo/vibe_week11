# 04: 접근 보호 (배포 전 필수)

**What to build:** 서버 함수는 화면을 거치지 않은 직접 요청으로도 호출될 수 있으므로, 모든 서버 함수가 요청의 접근 자격을 먼저 확인한다. 로그인 시스템 대신 환경 변수로 정한 암호 하나를 쓴다. 암호를 한 번 입력하면 그 기기의 브라우저에서 계속 쓸 수 있고, 암호가 설정되지 않은 환경(로컬 개발)에서는 보호를 끌 수 있다. Turso에 연결하거나 배포하기 전에 끝내야 한다.

**Blocked by:** 02 (화면이 서버 함수로 저장소 호출하기)

**Status:** ready-for-agent

- [ ] 암호가 설정된 환경에서는 암호를 모르는 사람의 모든 서버 함수 호출(직접 요청 포함)이 거부된다
- [ ] 암호를 입력하면 이후 그 브라우저에서는 다시 입력하지 않고 쓸 수 있다
- [ ] 암호가 설정되지 않은 환경에서는 보호가 꺼져 로컬 개발이 불편하지 않다
- [ ] 암호는 환경 변수로만 받고 소스와 저장소에 들어가지 않는다
- [ ] 틀린 암호를 넣으면 무엇이 잘못됐는지 화면에 알려 준다
- [ ] "자격이 없으면 거부, 있으면 통과"가 테스트로 확인된다
