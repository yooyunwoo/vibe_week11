# 05: 기존 브라우저 데이터 가져오기

**What to build:** 이 브라우저의 localStorage에 저장해 둔 Todo와 카테고리를 새 저장소로 한 번 옮긴다. 브라우저에 가져올 데이터가 있을 때만 안내가 보이고, 가져오기 전에 개수를 알려 주고, 끝나면 옮긴 개수를 알려 준다. `id`, 제목, 완료 여부, 생성 시각, 카테고리 연결을 그대로 옮기며, 같은 데이터를 여러 번 가져와도 중복이 생기지 않는다. 카테고리가 없던 시절에 저장된 Todo와 존재하지 않는 카테고리를 가리키는 Todo는 미분류로 가져온다. 모두 한 번에 저장해 실패해도 반쪽 데이터가 남지 않고, 브라우저의 원본 데이터는 자동으로 지우지 않는다.

**Blocked by:** 02 (화면이 서버 함수로 저장소 호출하기)

**Status:** ready-for-agent

- [ ] 저장 모듈에 "일괄 가져오기" async 함수가 추가되고, 이미 있는 `id`는 건너뛴다(여러 번 실행해도 같은 결과)
- [ ] 옛 형식(카테고리 연결 없음)과 존재하지 않는 카테고리를 가리키는 Todo가 미분류로 가져와진다
- [ ] 가져오기는 전부 성공하거나 전부 실패하며, 실패하면 아무것도 저장되지 않는다
- [ ] 제목, 완료 여부, 생성 시각, 카테고리 연결이 그대로 옮겨지고 목록 순서가 같다
- [ ] 브라우저에 가져올 데이터가 있을 때만 가져오기 안내가 보이고, 가져오기 전에 개수를 알려 준다
- [ ] 가져오기가 끝나면 옮긴 개수를 알려 주고, 실패하면 원인을 알리며 브라우저의 원본 데이터는 그대로다
- [ ] 가져온 뒤에도 브라우저의 원본 데이터를 자동으로 지우지 않는다
- [ ] 일괄 가져오기의 동작(멱등, 전부 또는 전무, 미분류 처리)이 로컬 데이터베이스 테스트로 확인된다
