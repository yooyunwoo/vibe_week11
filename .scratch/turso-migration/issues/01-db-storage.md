# 01: 데이터베이스 저장 모듈 (로컬 파일 DB)

**What to build:** 저장 모듈의 기존 async 인터페이스는 그대로 두고, 구현을 localStorage에서 데이터베이스로 바꾼다. 이 단계에서는 인터넷 없이 로컬 파일 데이터베이스(Turso 클라이언트 라이브러리로 연다)만 쓴다. Todo 표와 카테고리 표를 만들고, 카테고리를 지우면 그 Todo의 카테고리 참조가 자동으로 비워지게(미분류) 한다. 표를 한 번의 명령으로 만드는 스크립트를 둔다. 제목과 카테고리 이름 규칙(공백 제거, 빈 이름과 중복 이름 거부 등)은 저장 모듈에 그대로 둔다.

**Blocked by:** None (can start immediately)

**Status:** done

- [x] Turso 클라이언트 라이브러리가 설치되고 로컬 파일 데이터베이스를 열 수 있다
- [x] Todo와 카테고리 표가 있고, 카테고리 삭제 시 그 Todo의 카테고리가 자동으로 비워진다(외래 키 `ON DELETE SET NULL`)
- [x] 표를 만드는 명령이 있고, 이미 있으면 아무것도 바꾸지 않는다
- [x] 기존 저장 모듈 테스트(Todo와 카테고리의 모든 동작, 규칙, 정렬, 존재하지 않는 항목 무시)가 데이터베이스 구현으로 통과한다
- [x] 테스트는 인터넷 없이 로컬 데이터베이스에서 돌고, 각 테스트는 빈 데이터베이스로 시작한다
- [x] 저장 모듈의 공개 함수 이름, 인자, 반환 형태가 이전과 같다
- [x] 구현 전에 프로젝트의 Next.js 문서를 확인했다(AGENTS.md 지침)
