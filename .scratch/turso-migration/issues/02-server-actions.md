# 02: 화면이 서버 함수로 저장소 호출하기

**What to build:** 브라우저 화면이 저장 모듈을 직접 부르던 구조를 바꿔, 서버 함수(Server Action)를 통해서만 부르게 한다. 데이터베이스 접속은 서버에서만 일어나고 브라우저 코드에는 들어가지 않는다. 화면과 동작은 이전과 똑같고, 불러오는 중에는 "할 일이 없어요" 안내가 보이지 않으며, 서버 호출이 실패하면 변경이 반영된 것처럼 보이지 않고 사용자에게 무엇이 잘못됐는지 알린다. 이 단계의 앱은 로컬 파일 데이터베이스로 끝까지 동작한다. ADR-0003(Turso 선택, 서버에서만 접근, 서버 함수 경유)을 이 티켓에서 쓴다.

**Blocked by:** 01 (데이터베이스 저장 모듈 (로컬 파일 DB))
