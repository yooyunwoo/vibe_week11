# 03: 상태 필터 (전체 / 남은 것 / 완료)

**What to build:** 필터 버튼으로 전체 / 남은 것 / 완료 Todo만 골라 본다. 선택된 필터는 눈에 띄게 표시되고, 시작은 "전체"이며 저장하지 않는다. 남은 할 일 개수와 "완료된 항목 모두 삭제"는 필터와 상관없이 전체 Todo 기준이다. 필터에 맞는 Todo가 없으면 필터별 안내("남은 할 일이 없어요!", "완료한 할 일이 없어요")를 보여준다.

**Blocked by:** 01 (테스트 기반 만들기), 02 (빈 목록 안내 문구)

**Status:** done

- [x] 앱을 열면 "전체"가 선택되어 있다
- [x] "남은 것"/"완료" 필터에서 해당 Todo만 보인다
- [x] "남은 것" 필터에서 Todo를 완료하면 목록에서 바로 사라지고, "완료" 필터에서 체크를 해제해도 마찬가지다
- [x] 필터를 바꿔도 남은 할 일 개수는 전체 Todo 기준이다

- [x] 필터 계산이 테스트로 확인된다
