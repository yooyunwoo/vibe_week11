# 07: 카테고리 필터

**What to build:** 카테고리 필터(전체 / 미분류 / 각 카테고리)를 상태 필터와 함께(AND) 적용한다. 저장하지 않고 앱을 열면 "전체"로 시작한다. 선택 중인 카테고리를 삭제하면 필터가 "전체"로 돌아간다. 남은 할 일 개수와 "완료된 항목 모두 삭제"는 두 필터와 상관없이 전체 Todo 기준이다. 보여줄 Todo가 없을 때의 안내도 포함한다.

**Blocked by:** 03 (상태 필터 (전체 / 남은 것 / 완료)), 05 (카테고리 만들기·삭제 + 추가할 때 분류하기)
