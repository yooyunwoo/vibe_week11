# 05: 카테고리 만들기·삭제 + 추가할 때 분류하기

**What to build:** 카테고리를 직접 만들고 삭제한다. 이름은 앞뒤 공백을 제거하고 빈 이름과 이미 있는 이름(대소문자 구분 없음)은 거부한다. 삭제 전에 확인창이 뜨고, 삭제해도 그 Todo는 남고 미분류가 된다. Todo를 추가할 때 드롭다운으로 카테고리를 고르고(기본 미분류), 각 Todo에 카테고리 라벨이 보인다(미분류는 라벨 없음). 카테고리 기능 이전에 저장된 Todo와 사라진 카테고리를 가리키는 Todo는 오류 없이 미분류로 읽힌다. ADR-0002(카테고리는 별도 목록으로 저장)와 용어집 반영을 이 티켓에서 확인한다.

**Blocked by:** 01 (테스트 기반 만들기)

**Status:** done

- [x] 카테고리 조회/추가/삭제 저장 함수가 async로 추가되고 UI는 `localStorage`를 직접 쓰지 않는다
- [x] 카테고리는 별도 목록으로 저장되고 Todo는 `categoryId`(없으면 null)로 가리킨다
- [x] 공백 제거, 빈 이름 거부, 중복 이름 거부가 동작한다
- [x] 카테고리를 삭제하면 확인창이 뜨고 그 Todo는 삭제되지 않고 미분류가 된다
- [x] 추가할 때 드롭다운으로 카테고리를 고를 수 있고 기본값은 미분류이다
- [x] 카테고리 라벨이 Todo 옆에 보이고 미분류에는 라벨이 없다
- [x] 카테고리 없이 저장된 기존 Todo와 존재하지 않는 카테고리를 가리키는 Todo가 미분류로 읽힌다
- [x] 카테고리가 새로고침 후에도 남아 있다
- [x] 저장 모듈 동작이 테스트로 확인된다
