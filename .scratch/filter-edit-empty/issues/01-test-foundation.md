# 01: 테스트 기반 만들기

**What to build:** 테스트 러너(예: Vitest)와 `localStorage` 대체 환경을 도입한다. 기존 저장 함수(추가, 완료 토글, 삭제, 완료 항목 삭제)를 테스트로 고정하고, "화면에 보여줄 Todo를 고르는 계산"을 화면 밖 순수 함수로 분리한다. 사용자가 보는 동작은 바뀌지 않는다.

**Blocked by:** None (can start immediately)

**Status:** done

- [x] 테스트 러너가 설치되어 한 번의 명령으로 실행된다
- [x] 저장 모듈의 기존 동작(추가, 토글, 삭제, 완료 항목 삭제, 깨진/빈 저장 데이터 시 빈 목록)이 테스트로 확인된다
- [x] 보여줄 Todo를 고르는 계산이 순수 함수로 분리되고 입출력만 테스트된다
- [x] 화면 동작은 이전과 똑같고 타입 검사와 린트가 통과한다
